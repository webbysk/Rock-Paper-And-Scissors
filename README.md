# ✊ Rock Paper Scissors

A simple and interactive **Rock Paper Scissors game** built using **HTML, CSS, and JavaScript**.

The player competes against the computer, which randomly selects Rock, Paper, or Scissors. The game keeps track of the score and displays the result after every round.

## 🎮 Features

- ✊ Rock, 📄 Paper, and ✂️ Scissors choices
- 🤖 Computer-generated random choices
- 🏆 Automatic win/loss/tie detection
- 📊 Real-time score tracking
- 🔄 Reset game functionality
- 💬 Dynamic result messages
- 📱 Responsive design
- 🎨 Modern and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Game logic and interactivity

## 🧠 How It Works

The game follows the classic rules:

| Player | Computer | Result |
|---|---|---|
| Rock | Scissors | 🏆 Player Wins |
| Paper | Rock | 🏆 Player Wins |
| Scissors | Paper | 🏆 Player Wins |
| Same Choice | Same Choice | 🤝 Tie |

Otherwise, the computer wins the round.
